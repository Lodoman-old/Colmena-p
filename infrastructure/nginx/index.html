Configuracion del Sistema

Los cambios requieren reiniciar el servidor backend

Configuración de Firebase Cloud Messaging. Ve a Firebase Console → Project Settings → Cloud Messaging para obtener estos valores.

Los cambios se aplican al instante. Para cambiar de proyecto Firebase (dev → prod), actualiza estos valores y regenera el APK con la nueva google-services.json.

Las fotos de evidencia se guardan en este servidor por defecto. Con Cloudflare R2 se guardan en la nube (10 GB gratis, sin costo por descargas). Si configuras R2, las fotos nuevas suben directo a la nube y puedes migrar las ya guardadas.

Pasos para crear la cuenta y bucket (5 min):
  1. Crea tu cuenta gratis en dash.cloudflare.com.
  2. Menú lateral: R2 → Crear bucket (ej: evidencias-colmena).
  3. En el bucket: Settings → Public access → activa R2.dev subdomain y copia la URL pública (ej: https://pub-abc123.r2.dev).
  4. En R2: Manage R2 API Tokens → Create API token → permiso Object Read & Write (todos los buckets o solo el tuyo). Copia Access Key ID y Secret Access Key.
  5. Pega todo abajo, guarda y pulsa Probar conexión.

El Secret Access Key queda guardado en la base de datos (como el resto de la configuración). Las fotos ya en R2 no se vuelven a subir (detección automática).

Compartir App PRIoridad Territorial

Escanea el codigo QR con el celular o toca el boton para descargar la APK

Si la descarga no inicia, abre la URL con el navegador del celular (Chrome o el que venga).

En el iPhone usa la version web (PWA) como app:

  1. Abre Safari y entra a la direccion de la app:

  1. Toca el boton Compartir (cuadro con flecha hacia arriba, abajo de la pantalla).
  2. Desliza las opciones y toca Agregar a pantalla de inicio (Add to Home Screen).
  3. Toca Agregar en la esquina superior derecha.
  4. La app aparece como icono en el home del iPhone; abrela desde ahi para usarla a pantalla completa.

Nota: en iPhone la sincronizacion se realiza al abrir la app (iOS no permite sync en segundo plano).
